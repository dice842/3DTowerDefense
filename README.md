# 3D Tower Defense

Unity와 C#을 학습하며 제작한 간단한 3D 타워 디펜스 프로젝트입니다.

적이 정해진 경로를 따라 이동하고, 타일에 타워를 설치하여 범위 안의 적을 공격하는 기본적인 타워 디펜스 기능을 구현했습니다.

## 개발 환경

- Unity 2022.3.7f1
- C#

## 주요 기능

- Waypoint를 이용한 적 이동
- 타일 클릭을 통한 타워 설치
- 범위 내 적 탐색 및 공격
- 적 체력 및 피격 처리
- 타일 좌표 표시

## Scripts

### EnemyMover.cs
등록된 Waypoint를 순서대로 따라가며 적을 이동시킵니다.

### EnemyHealth.cs
적의 체력을 관리하고 공격을 받으면 체력을 감소시킵니다.

### Waypoint.cs
타워를 설치할 수 있는 타일인지 확인하고 마우스 클릭 시 타워를 생성합니다.

### CoordinateLabeler.cs
타일의 좌표를 표시하고 타워 설치 가능 여부에 따라 좌표의 색상을 변경합니다.

### TargetLocator.cs
타워의 공격 범위 안에 있는 적을 탐색하고 가장 가까운 적을 바라보며 공격합니다.
